# Tidesstunes Social Pipeline

Case study only. No source code, credentials, prompts, databases, logs, or API keys are included.

Public page: [Tidesstunes Social Pipeline](https://www.ai.joaoqueiros.com/systems/tidesstunes-social-pipeline)  
Public demo: [guided walkthrough](https://www.ai.joaoqueiros.com/demo/tidesstunes-social-pipeline.html)

## Problem

Long-form music videos need to be converted into short vertical clips, captioned differently for each social platform, uploaded, queued, and tracked. Doing that manually is repetitive and easy to abandon after a few busy weeks.

## System Pattern

The pipeline converts YouTube music videos into short 9:16 clips, prepares platform-specific captions, sends approved assets through a scheduler, and tracks queue status across TikTok, Instagram Reels, and Pinterest.

## Stack

Python, FFmpeg, Cloudinary, Buffer API, YouTube source media, platform-specific caption templates, human review before publishing.

## Outcome

The system turns a manual distribution routine into a repeatable content pipeline. The studio can process a batch of music videos, generate social-ready assets, and keep a consistent posting rhythm with far less manual handling.
