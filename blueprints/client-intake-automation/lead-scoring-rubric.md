# Lead Scoring Rubric

The score is a triage aid, not a final decision. The reviewer can override it.

## Score Categories

| Category | Weight | What it measures |
|---|---:|---|
| Service match | 30 | Whether the request fits the studio's actual offer. |
| Problem clarity | 25 | Whether the prospect explains a real operational pain. |
| Timeline | 20 | Whether the request has a clear and reasonable start window. |
| Budget clarity | 15 | Whether the prospect has a budget range or buying intent. |
| Tool readiness | 10 | Whether existing tools are named clearly enough to scope next steps. |

## Scoring Guide

| Score band | Meaning | Recommended action |
|---|---|---|
| 80-100 | Strong fit | Draft a discovery call response for review. |
| 60-79 | Likely fit with gaps | Draft focused follow-up questions. |
| 40-59 | Unclear fit | Hold or request more context before booking. |
| 0-39 | Weak fit | Draft a polite decline or redirect. |

## Category Detail

### Service Match

| Score | Meaning |
|---:|---|
| 30 | Request clearly matches the offer. |
| 20 | Request is adjacent and may fit with framing. |
| 10 | Request is broad or partially outside the offer. |
| 0 | Request is clearly outside scope. |

### Problem Clarity

| Score | Meaning |
|---:|---|
| 25 | The pain, current process, and desired outcome are clear. |
| 15 | The pain is clear but the current process is vague. |
| 5 | The request is mostly a general interest note. |
| 0 | No meaningful problem is stated. |

### Timeline

| Score | Meaning |
|---:|---|
| 20 | Clear, reasonable timeline. |
| 12 | Timeline exists but is flexible or slightly vague. |
| 5 | Timeline is urgent without enough context. |
| 0 | No timeline given. |

### Budget Clarity

| Score | Meaning |
|---:|---|
| 15 | Budget range or buying process is defined. |
| 10 | Budget is not final but there is clear buying intent. |
| 5 | Prospect is researching with no range yet. |
| 0 | No budget signal. |

### Tool Readiness

| Score | Meaning |
|---:|---|
| 10 | Existing tools and workflow are named. |
| 6 | Some tools are mentioned but workflow is unclear. |
| 3 | Tools are unknown, but process pain is clear. |
| 0 | No tool or workflow context. |

## Reviewer Notes

- Do not reject automatically because budget is unclear.
- Do not approve automatically because the score is high.
- Prioritize clear operational pain over vague interest in AI.
- Ask follow-up questions when a good-fit lead lacks one critical detail.
