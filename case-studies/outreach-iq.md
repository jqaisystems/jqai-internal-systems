# OutreachIQ

Case study only. No source code, credentials, prompts, databases, logs, prospect lists, or API keys are included.

Public page: [OutreachIQ](https://www.ai.joaoqueiros.com/systems/outreach-iq)  
Public demo: [guided walkthrough](https://www.ai.joaoqueiros.com/demo/outreach-iq.html)

## Problem

Finding good prospects is only the first step. The time disappears in enrichment, qualification, deciding who is worth contacting, drafting a relevant first message, and tracking the next action.

## System Pattern

OutreachIQ combines search, enrichment, AI scoring, personalized draft generation, and pipeline tracking in one dashboard. The human reviews the lead, message, and next step before sending.

## Stack

Python, Flask, Claude API, Google Maps-style prospecting, Firecrawl-style website analysis, Apollo-style enrichment, dashboard review queue, CSV export.

## Outcome

The system compresses multi-day manual prospecting into a structured review workflow. It improves consistency by applying the same scoring rubric and drafting pattern to every lead.
